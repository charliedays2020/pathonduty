# PathOnDuty · página pública

Página web pública de **PathOnDuty**, la edición para el grupo y la familia de TrackOnDuty (`com.carlday.pathonduty`).

| Archivo | Para qué sirve |
|---|---|
| `index.html` | Página de la app |
| `privacidad.html` | Política de privacidad, la que pide Google Play |
| `play/` | Icono, gráfico destacado y capturas de la ficha de Google Play |

- Se publica con GitHub Pages desde `main`.
- El código de la app no está aquí: vive en el repositorio privado `TrackOnDuty`.
- No mover ni renombrar este repositorio: la dirección de la política de privacidad está registrada en Google Play.
